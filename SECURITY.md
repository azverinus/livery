# Security policy

## Supported versions

Security fixes go into the latest release of the latest major version.

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/azverinus/livery/security/advisories/new), not in a public issue. Include what an attacker can do, the steps or manifest that reproduce it, and the livery version.

You will get a reply within a week. Once a fix is released, the advisory is published with credit to you unless you ask otherwise.
